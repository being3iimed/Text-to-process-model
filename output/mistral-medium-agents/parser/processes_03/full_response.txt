### **5. Recommendations for Extension**
If the process evolves to include:
1. **Supplier selection rules** → Add `XOR` gateway with conditions (e.g., `if (supplier_A_available)`).
2. **SLA for inspection** → Add `timerBoundary("PT2H")` to `userTask("Inspect stock quality")`.
3. **Parallel tasks** → Use `AND` gateway (e.g., update system while placing order).
4. **Error handling** → Add `errorBoundary` to `serviceTask("Place order...")` for failed submissions.

**Current design is intentionally minimalist to match described logic.**
