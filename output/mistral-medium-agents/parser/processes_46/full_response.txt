#### **TASKS**
- **`serviceTask("Read order from automatic order management system")`**
  - Automated system action to fetch order details.
- **`serviceTask("Check stock availability for product")`**
  - Automated check for product availability in warehouse.
- **`serviceTask("Withdraw product from warehouse")`**
  - Automated warehouse operation.
- **`serviceTask("Reorder product from wholesaler")`**
  - Automated system action to place reorder.

- **`serviceTask("Check if entire order is ready for shipment")`**
  - Automated order completion verification.
- **`sendTask("Send: courier request")`**
  - One-way communication to courier service.
- **`serviceTask("Pack products")`**
  - Automated or manual packing process.
- **`serviceTask("Ship order")`**
  - Final shipment execution.

- **XOR (Exclusive Gateway) at "Stock Check"**

    - `in_stock == true` → Withdraw from warehouse
    - `in_stock == false` → Reorder from wholesaler
- **XOR (Exclusive Gateway) at "Order Completion Check"**
  - Conditions:
    - `order_ready == true` → Proceed to shipment

- **`intermediateEvent(timerBoundary("10 days"))`**

  - **Handler**: Single immediate action (`Demand penalty`).

```pseudocode
startEvent("Order received from automatic system")

// --- Initial Stock Check ---
serviceTask("Read order from automatic order management system")
serviceTask("Check stock availability for product")

if (in_stock == true):
    serviceTask("Withdraw product from warehouse")
else:
    serviceTask("Reorder product from wholesaler")
    receiveTask("Receive: reordered product"):
        timerBoundary("10 days"):
            serviceTask("Demand delivery delay penalty from wholesaler")
end_if

// --- Post-Stock Actions ---
serviceTask("Register product in stock management system")
serviceTask("Check if entire order is ready for shipment")

if (order_ready == true):
    AND:
        sendTask("Send: courier request")
        serviceTask("Pack products")
    END_AND
    serviceTask("Ship order")
    endEvent("Order shipped")
else:
    // Loop: Process next product
    serviceTask("Select next product from order")
    // Re-enter stock check (implicit loop)
    serviceTask("Check stock availability for product")
end_if
```
