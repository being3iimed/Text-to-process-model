<summary_of_elements>

### TASKS:
- **userTask("Receive Order")** - Initial human interaction to receive order
- **userTask("Ask: Menu or Burger Only?")** - Decision point for order type
- **serviceTask("Prepare Drink")** - Automated drink preparation (variable duration)
- **userTask("Ask: Fries or Wedges?")** - Decision point for side choice
- **serviceTask("Prepare Fries")** - Automated fries preparation (variable duration)
- **serviceTask("Prepare Wedges")** - Automated wedges preparation (variable duration)
- **serviceTask("Prepare Burger")** - Automated burger preparation (variable duration)
- **sendTask("Send: Status Update")** - Enthusiastic status updates every 30 seconds
- **serviceTask("Deliver via Conveyor Belt")** - Final delivery mechanism

### GATEWAYS:
- **XOR** after "Ask: Menu or Burger Only?" with 2 branches:
  - "menu" → Prepare Drink
  - "burger only" → Skip to burger preparation
- **XOR** after "Ask: Fries or Wedges?" with 2 branches:
  - "fries" → Prepare Fries
  - "wedges" → Prepare Wedges

### EVENTS:
- **startEvent("Order Received")** - Manual trigger
- **endEvent("Order Delivered")** - Process completion
- **intermediateEvent(timerBoundary("PT30S"))** - Status update timer (repeating)

### BOUNDARY EVENTS:
- **timerBoundary("PT30S")** on "Prepare Burger" - Justified by explicit requirement for status updates

### SUBPROCESSES:
- **subProcess("Prepare Side Dish")** - Purpose: Cohesive grouping of side dish preparation logic
  - Justification: Logical grouping of related tasks (fries/wedges decision + preparation)

</summary_of_elements>

<pseudocode>
startEvent("Order Received")

// Main Process Flow
userTask("Receive Order")
userTask("Ask: Menu or Burger Only?")

// Menu Decision
if (customer_wants_menu):
    serviceTask("Prepare Drink") // Variable duration based on size
    subProcess("Prepare Side Dish"):
        startEvent("Side Dish Preparation Start")
        userTask("Ask: Fries or Wedges?")
        if (customer_wants_fries):
            serviceTask("Prepare Fries") // Variable duration based on size
        else:
            serviceTask("Prepare Wedges") // Variable duration based on size
        endEvent("Side Dish Ready")
    endSubProcess
else:
    // Skip drink and sides for burger-only orders
    // (No action needed - flows directly to burger preparation)
end_if

// Burger Preparation with Status Updates
serviceTask("Prepare Burger"):
    timerBoundary("PT30S"):
        sendTask("Send: Status Update")
end_serviceTask

// Delivery
serviceTask("Deliver via Conveyor Belt")
endEvent("Order Delivered")
</pseudocode>
