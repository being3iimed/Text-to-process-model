### Summary of Elements

**TASKS:**
- `serviceTask("Check Inventory Availability")` - System checks stock for all products
- `userTask("Manager Decides on Partial Shipment")` - Manager chooses between partial shipment or waiting
- `serviceTask("Split Order into Shipments")` - System divides order based on availability
- `sendTask("Send: Shortage Notification")` - System notifies manager of insufficient stock
- `serviceTask("Reserve Available Inventory")` - System reserves stock for immediate packing
- `serviceTask("Schedule Packing")` - System schedules packing for available items
- `serviceTask("Hold Order in Pending Status")` - System places order on hold
- `serviceTask("Ship Available Items")` - System ships available items
- `serviceTask("Ship Backordered Items")` - System ships remaining items when stock arrives

**GATEWAYS:**
- XOR at inventory check with conditions (all available, partial available, none available)
- XOR at manager decision with conditions (partial shipment, wait for full stock)

**EVENTS:**
- `startEvent("Bulk Order Submitted")` - Trigger: manual (manager submits order)
- `endEvent("Order Fulfilled")` - Normal completion
- `intermediateEvent(timerBoundary("PT24H"))` - Wait for backordered items (if applicable)

**BOUNDARY EVENTS:**
- `timerBoundary("PT24H")` on `serviceTask("Hold Order in Pending Status")` - SLA: Manager must respond within 24 hours

**SUBPROCESSES:**
- Subprocess "Order Fulfillment" - Purpose: Handle inventory check, manager decision, and shipment processing
  - Justification: Cohesive logical grouping of order fulfillment steps

### BPMN Pseudocode

```pseudocode
startEvent("Bulk Order Submitted")

serviceTask("Check Inventory Availability")

if (all_products_available):
    serviceTask("Reserve Available Inventory")
    serviceTask("Schedule Packing")
    endEvent("Order Fulfilled")
else if (partial_products_available):
    sendTask("Send: Shortage Notification")
    userTask("Manager Decides on Partial Shipment"):
        timerBoundary("24 hours"):
            sendTask("Send: reminder to manager")
    if (partial_shipment_chosen):
        serviceTask("Split Order into Shipments")
        serviceTask("Ship Available Items")
        serviceTask("Hold Order in Pending Status"):
            intermediateEvent(timerBoundary("PT24H")):
                serviceTask("Ship Backordered Items")
        endEvent("Order Fulfilled")
    else:
        serviceTask("Hold Order in Pending Status"):
            intermediateEvent(timerBoundary("PT24H")):
                serviceTask("Ship Complete Order")
        endEvent("Order Fulfilled")
else:
    sendTask("Send: Full Shortage Notification")
    serviceTask("Hold Order in Pending Status"):
        intermediateEvent(timerBoundary("PT24H")):
            serviceTask("Cancel Order")
    endEvent("Order Processed")
```
