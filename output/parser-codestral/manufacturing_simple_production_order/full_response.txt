```
TASKS:
- userTask("Production Manager Creates Work Order") - reason: Human judgment required for work order creation
- serviceTask("Pull Bill of Materials (BOM)") - reason: Automated system action to retrieve BOM
- serviceTask("Reserve Raw Materials from Inventory") - reason: Automated system action to reserve materials
- userTask("Schedule Production Line") - reason: Human judgment required for scheduling
- serviceTask("Manufacture Components According to Specifications") - reason: Automated system action to manufacture components
- userTask("Perform Quality Check") - reason: Human judgment required for quality assessment

GATEWAYS:
- XOR at point after quality check with conditions: passes, fails (default)

EVENTS:
- startEvent("Process Begins") - trigger: manual
- endEvent("Process Complete") - normal completion

BOUNDARY EVENTS:
- None

SUBPROCESSES:
- None
```
