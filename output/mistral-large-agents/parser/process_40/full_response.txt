## Summary of Elements

### TASKS:
- **serviceTask("Collect Machine Data")** - Automated data collection from machine sensors/API
- **scriptTask("Computation: Calculate OEE")** - Mathematical computation of OEE using collected data
- **serviceTask("Stop Machine")** - Automated command to halt machine operation
- **sendTask("Send: OEE Alert to Engineer")** - Email notification to engineer
- **serviceTask("Monitor Machine Connection")** - Continuous check for machine connectivity

### GATEWAYS:
- **XOR** after OEE calculation to check threshold (2 branches: below threshold, at/above threshold)
- **XOR** after machine stop to wait for restart (2 branches: machine restarted, machine disconnected)

### EVENTS:
- **messageStartEvent("MachineConnected")** - Process triggered when machine connects
- **endEvent("Process Terminated")** - Normal completion when machine disconnects
- **intermediateEvent(timerBoundary("PT1M"))** - 1-minute interval for data collection

### BOUNDARY EVENTS:
- **timerBoundary("PT5M")** on "Monitor Machine Connection" - SLA: Check connection every 5 minutes
- **errorBoundary()** on "Collect Machine Data" - Error: Sensor/API failure (explicit scenario)

### SUBPROCESSES:
- **subProcess("OEE Calculation Loop")** - Purpose: Encapsulates the repeating measurement cycle
  - Justification: Logical grouping of 3+ related tasks (collect, calculate, evaluate) with clear purpose

### TIMER VALIDATION:
- All timer properties use ISO 8601 format:
  - Data collection interval: `PT1M` (1 minute)
  - Connection check SLA: `PT5M` (5 minutes)

### GATEWAY CONVERGENCE:
- All XOR gateways have explicit merge points
- No orphaned paths

// MAIN PROCESS
process("OEE Monitoring Process"):
    messageStartEvent("MachineConnected")

    subProcess("OEE Calculation Loop"):
        startEvent("Measurement Cycle Start")

        // Data Collection with Error Handling
        serviceTask("Collect Machine Data"):
            errorBoundary():
                sendTask("Send: Sensor Failure Alert")
                endEvent("Measurement Aborted")

        scriptTask("Computation: Calculate OEE")

        // Threshold Check
        if (OEE < threshold_percentage):
            serviceTask("Stop Machine")
            sendTask("Send: OEE Alert to Engineer")

            // Wait for Restart or Disconnection
            if (machine_restarted):
                intermediateEvent(timerBoundary("PT1M")) // Wait 1 min before restarting cycle
                loopBackTo: startEvent("Measurement Cycle Start")
            else if (machine_disconnected):
                endEvent("Machine Disconnected")
            END_IF
        else:
            intermediateEvent(timerBoundary("PT1M")) // Wait 1 min before next cycle
            loopBackTo: startEvent("Measurement Cycle Start")
        END_IF
    endSubProcess

    // Connection Monitoring (Parallel to Measurement)
    AND:
        subProcess("OEE Calculation Loop") // Runs continuously
        serviceTask("Monitor Machine Connection"):
            timerBoundary("PT5M"):
                sendTask("Send: Connection Timeout Alert")
    END_AND

    endEvent("Process Terminated")
endProcess

## Key Implementation Notes

1. **Threshold Configuration**:
   - `threshold_percentage` should be configurable (e.g., 85%)

2. **Machine Commands**:
   - "Stop Machine" requires API/safe protocol implementation
   - Restart detection via machine status polling

3. **Data Collection**:
   - Error boundary handles sensor/API timeouts
   - Consider adding retry logic before alerting

4. **Parallel Monitoring**:
   - Connection check runs independently of measurement cycle
   - Both paths converge at process termination

5. **Timer Precision**:
   - All durations use ISO 8601 for unambiguous interpretation
   - `PT1M` = 1 minute interval between measurements
   - `PT5M` = 5 minute connection check SLA

6. **Process Termination**:
   - Only occurs on explicit disconnection
   - All other scenarios loop or wait
