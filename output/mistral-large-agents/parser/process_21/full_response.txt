// Main Process: Goods Shipping Orchestration
startEvent("Shipping Process Initiated")

// Step 1: Determine shipping approach
userTask("Clarify Shipping Responsibility")

if (amount == "large"):
    // Special shipping path for large amounts
    userTask("Invite Logistic Companies for Offers")
    userTask("Select Logistic Company")

    // Parallel preparation while logistics are arranged
    AND:
        serviceTask("Package Goods")  // Warehousemen can work in parallel
        userTask("Write Package Label")  // Secretary prepares documentation
    END_AND

    // Insurance decision (explicit branch)
    userTask("Decide on Parcel Insurance")
    if (insurance_needed == true):
        userTask("Take Parcel Insurance")  // Logistics head action
    else:
        // No action needed (default flow)
    END_IF

else:  // Default path for small amounts
    AND:
        serviceTask("Package Goods")
        userTask("Write Package Label")
    END_AND
END_IF

// Final synchronization before pickup
serviceTask("Prepare for Pickup")
endEvent("Goods Ready for Pickup")

## Recommendations for Process Optimization
1. **Explicit Criteria for "Large" vs "Small"**:
   - Define threshold (e.g., weight/volume) to automate the initial XOR decision.
   - *Example*: `if (weight_kg > 50)`.

2. **Parcel Insurance Rules**:
   - Codify insurance requirements (e.g., value > €1000) to replace manual decision.
   - *Example*: `if (goods_value > 1000)`.

3. **Parallelism Validation**:
   - Confirm `Package Goods` and `Write Package Label` can truly occur concurrently.
   - If dependencies exist, replace `AND` with sequential flow.

4. **Logistics Integration**:
   - For large shipments, consider a `businessRuleTask` to auto-select the cheapest/fastest offer based on predefined criteria.
