GATEWAYS:
- XOR after initial validation (valid/invalid)
- XOR after each question (pass/fail/conditional)
- XOR after sensor data collection (within spec/out of spec)

EVENTS:
- startEvent("Inspection Process Started") - Manual trigger
- endEvent("Inspection Complete") - Normal completion

BOUNDARY EVENTS:

startEvent("Inspection Process Started")

// Initial Setup
userTask("Enter machine type")
userTask("Enter serial number")
serviceTask("Validate machine type and serial number")

if (validation_result == "invalid"):
    endEvent("Inspection Aborted")
else:
    // Main Inspection Flow
    subProcess("Sensor Data Collection"):
        startEvent("Begin Data Collection")

        // Parallel data collection
        AND:
            serviceTask("Collect temperature readings")
            serviceTask("Collect pressure readings")
            serviceTask("Collect flow rate measurements")
        END_AND

        userTask("Review collected sensor values")

        if (any_reading_out_of_spec):
            userTask("Answer: Explain deviation cause")
            userTask("Answer: Corrective action taken?")
        end_if

        endEvent("Data Collection Complete")
    endSubProcess

    // Question Series
    userTask("Answer: Visual inspection of seals")
    if (seal_issue_detected):
        userTask("Answer: Seal issue severity")
        userTask("Answer: Immediate action required?")
    end_if

    userTask("Answer: Noise level assessment")
    userTask("Answer: Vibration check")

    // Final Review
    userTask("Review all inspection findings")
    userTask("Confirm inspection completion")

    endEvent("Inspection Complete")
end_if
