<summary_of_elements>

### TASKS:
- **userTask("Receive Order")** - Initial order reception (human interaction)
- **userTask("Ask: Menu or Burger Only?")** - Decision point for order type
- **serviceTask("Prepare Drink")** - Automated drink preparation (variable time)
- **userTask("Ask: Fries or Wedges?")** - Side dish selection
- **serviceTask("Prepare Fries")** - Automated fries preparation (variable time)
- **serviceTask("Prepare Wedges")** - Automated wedges preparation (variable time)
- **serviceTask("Prepare Burger")** - Automated burger preparation (variable time)
- **sendTask("Send: Status Update")** - Enthusiastic progress notifications (every 30s)
- **serviceTask("Deliver via Conveyor Belt")** - Automated delivery

### GATEWAYS:
- **XOR** after "Ask: Menu or Burger Only?" (2 branches: Menu/Burger Only)
- **XOR** after "Ask: Fries or Wedges?" (2 branches: Fries/Wedges)
- **AND** for parallel status updates during burger prep (timer + burger prep)

### EVENTS:
- **startEvent("Order Received")** - Manual trigger
- **endEvent("Order Delivered")** - Process completion
- **intermediateEvent(timerBoundary("PT30S"))** - Status update timer

### BOUNDARY EVENTS:
- **timerBoundary("PT30S")** on "Prepare Burger" - Enthusiastic status updates (explicit requirement)

### SUBPROCESSES:
- **subProcess("Prepare Menu Components")** - Groups drink + side preparation
  - Justification: Cohesive logical grouping of menu-specific tasks (3+ related tasks)

</summary_of_elements>

<pseudocode>
startEvent("Order Received")

// Main Process Flow
userTask("Receive Order")
userTask("Ask: Menu or Burger Only?")

if (customer_wants_menu):
    subProcess("Prepare Menu Components"):
        startEvent("Menu Prep Start")

        // Parallel drink + side preparation
        AND:
            serviceTask("Prepare Drink")  // Variable time
            userTask("Ask: Fries or Wedges?")

            if (customer_wants_fries):
                serviceTask("Prepare Fries")  // Variable time
            else:
                serviceTask("Prepare Wedges")  // Variable time
        END_AND

        endEvent("Menu Components Ready")
    endSubProcess

    // Burger preparation with status updates
    serviceTask("Prepare Burger"):
        timerBoundary("PT30S"):
            sendTask("Send: Status Update")
    endBoundary
else:
    // Burger-only path
    serviceTask("Prepare Burger"):
        timerBoundary("PT30S"):
            sendTask("Send: Status Update")
    endBoundary

// Delivery
serviceTask("Deliver via Conveyor Belt")
endEvent("Order Delivered")
</pseudocode>
