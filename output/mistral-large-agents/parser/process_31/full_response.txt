Here's the structured BPMN pseudocode for the Blizzard Online Character Generator process, with rigorous semantic validation:

```pseudocode
// ===== MAIN PROCESS: Character Creation =====
startEvent("User Initiates Character Creation")

// Parallel account setup and name brainstorming
AND:
    // Account Setup Branch
    subProcess("Account Setup"):
        startEvent("Account Setup Start")

        if (has_battle_net_account):
            serviceTask("Verify Battle.net Account")
        else:
            userTask("Enter Account Information")
            receiveTask("Receive: confirmation email")
            userTask("Click Confirmation Link")
        END_IF

        if (has_active_wow_subscription):
            serviceTask("Validate Subscription")
        else:
            userTask("Select Payment Method")

            if (payment_method == "credit_card"):
                userTask("Enter Credit Card Information")
            else if (payment_method == "bank_account"):
                userTask("Enter IBAN and BIC")
            END_IF

            serviceTask("Process Payment")
        END_IF

        serviceTask("Log into Game")
        userTask("Select Realm, Race, and Class")
        endEvent("Account Setup Complete")
    endSubProcess

    // Name Brainstorming Branch
    subProcess("Name Brainstorming"):
        startEvent("Name Brainstorming Start")
        userTask("Brainstorm Character Names")
        endEvent("Name Brainstorming Complete")
    endSubProcess
END_AND

// Name selection process
userTask("Enter First Name Proposal")
while (name_not_available):
    userTask("Enter Next Name Proposal")
END_WHILE

serviceTask("Reserve Character Name")
sendTask("Send: Character Confirmation")
sendTask("Send: Character Selfies")

// Expansion release notification
intermediateEvent(timerBoundary("PT1M")) // Minimal delay to ensure all previous steps complete
sendTask("Send: Expansion Release Notification")

endEvent("Character Creation Complete")
```

- **serviceTask("Verify Battle.net Account")** - Account validation
- **serviceTask("Validate Subscription")** - Subscription check
- **serviceTask("Process Payment")** - Payment processing
- **serviceTask("Log into Game")** - Game login

- **receiveTask("Receive: confirmation email")** - Email reception
- **sendTask("Send: Character Confirmation")** - Confirmation message

- **sendTask("Send: Expansion Release Notification")** - Expansion alert

#### **GATEWAYS**
- **AND Gateway** - Parallel branches for account setup and name brainstorming
- **XOR Gateway** - Battle.net account check (has account / needs creation)
- **XOR Gateway** - Subscription check (active / needs payment)
- **XOR Gateway** - Payment method selection (credit card / bank account)
- **WHILE Loop** - Name availability check (repeats until available)

#### **EVENTS**
- **startEvent("User Initiates Character Creation")** - Process trigger
- **timerBoundary("PT1M")** - Minimal delay before expansion notification
- **endEvent("Character Creation Complete")** - Process completion

#### **SUBPROCESSES**
- **Account Setup** - Purpose: Handle all account-related steps
  - Justification: Cohesive logical grouping of account operations
- **Name Brainstorming** - Purpose: Creative name generation
  - Justification: Clear separation of creative process
