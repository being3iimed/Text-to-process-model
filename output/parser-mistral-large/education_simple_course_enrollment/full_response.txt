## Summary of Elements

### TASKS:
- **userTask("Search for Courses")** - Student actively searches available courses
- **userTask("Check Course Details")** - Student reviews time, location, professor, prerequisites, enrollment cap
- **serviceTask("Validate Prerequisites")** - System checks if student meets prerequisites
- **serviceTask("Check Seat Availability")** - System verifies available seats
- **userTask("Confirm Enrollment")** - Student clicks enroll button
- **serviceTask("Process Enrollment")** - System handles enrollment logic
- **serviceTask("Generate Course Schedule")** - System creates updated schedule
- **serviceTask("Update Course Roster")** - System updates enrollment records

### GATEWAYS:
- **XOR after "Check Course Details"** with conditions:
  - `prerequisites_met AND seats_available`
  - `prerequisites_not_met OR seats_unavailable` (default)

### EVENTS:
- **startEvent("Course Enrollment Process Started")** - Manual trigger
- **endEvent("Enrollment Complete")** - Successful completion
- **endEvent("Enrollment Failed")** - Unsuccessful completion

### BOUNDARY EVENTS:
- None (no explicit SLA requirements or error scenarios mentioned)

### SUBPROCESSES:
- None (all tasks are linear/sequential with one decision point)

</summary_of_elements>

<bpmn_pseudocode>

## BPMN Pseudocode

```pseudocode
startEvent("Course Enrollment Process Started")

userTask("Search for Courses")
userTask("Check Course Details")

if (prerequisites_met AND seats_available):
    userTask("Confirm Enrollment")
    serviceTask("Process Enrollment")
    serviceTask("Generate Course Schedule")
    serviceTask("Update Course Roster")
    endEvent("Enrollment Complete")
else:
    endEvent("Enrollment Failed")
```
