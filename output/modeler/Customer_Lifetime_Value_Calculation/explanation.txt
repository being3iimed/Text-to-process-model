This JSON model represents the customer value analysis process with:

1. A single start event 2. Three script tasks for data analysis and segmentation 3. An exclusive gateway to route customers to appropriate strategy tasks 4. Three service tasks for different customer segments 5. A script task to update segmentation models 6. A single end event

All elements are properly connected with sequence flows, and the exclusive gateway has the correct conditions and default flow. The model follows BPMN 2.0 standards and can be imported into BPMN tools like Camunda Modeler or draw.io.
