### Summary of Elements

**TASKS**:
- userTask("Customer Initiates Return Request") - Customer provides order number and reason
- serviceTask("Validate Return Eligibility") - System checks if return is within 30 days and item condition
- sendTask("Send: Return Shipping Label") - System sends label to customer
- userTask("Customer Ships Item") - Customer ships item back
- userTask("Warehouse Verifies Item Condition") - Staff verify item condition
- serviceTask("Process Refund") - System processes refund
- sendTask("Send: Refund Confirmation Email") - System sends confirmation email
- sendTask("Send: Return Denied Notification") - System notifies customer of denied return

**GATEWAYS**:
- XOR at "Validate Return Eligibility" with conditions "eligible", "not eligible"
- XOR at "Warehouse Verifies Item Condition" with conditions "acceptable", "damaged"

**EVENTS**:
- startEvent("Customer Initiates Return Request") - trigger: manual
- endEvent("Process Complete") - normal completion

**BOUNDARY EVENTS**:
- None (no explicit SLA or error scenarios mentioned)

**SUBPROCESSES**:
- None (no cohesive logical grouping or repeated structures)
