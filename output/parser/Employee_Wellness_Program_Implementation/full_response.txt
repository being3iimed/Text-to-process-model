### Process Elements Summary

#### Tasks

1. **userTask("Assess Employee Health Needs")**
   - Purpose: Gather information about employee health needs through surveys or consultations
   - Type: userTask (requires human judgment)

2. **userTask("Design Wellness Program")**
   - Purpose: Create a wellness program based on assessed needs, offering activities like fitness challenges, mental health workshops, or nutrition counseling
   - Type: userTask (requires human judgment)

3. **userTask("Employee Enrollment")**
   - Purpose: Employees enroll voluntarily in the wellness program
   - Type: userTask (requires human judgment)

4. **serviceTask("Track Participation")**
   - Purpose: Monitor and record employee participation in the wellness program
   - Type: serviceTask (automated tracking)

5. **serviceTask("Evaluate Progress")**
   - Purpose: Assess employee progress through periodic health assessments
   - Type: serviceTask (automated evaluation)

6. **serviceTask("Generate Summary Report")**
   - Purpose: Create a summary report highlighting participation rates and health improvements
   - Type: serviceTask (automated report generation)

#### Gateways

1. **Exclusive Gateway (XOR)**
   - Purpose: Determine if the wellness program is designed based on assessed needs
   - Conditions:
     - If needs are assessed, proceed to design the program
     - If needs are not assessed, reassess needs

2. **Exclusive Gateway (XOR)**
   - Purpose: Determine if employees have enrolled in the wellness program
   - Conditions:
     - If employees have enrolled, proceed to track participation
     - If employees have not enrolled, wait for enrollment

3. **Exclusive Gateway (XOR)**
   - Purpose: Determine if progress has been evaluated
   - Conditions:
     - If progress has been evaluated, proceed to generate the summary report
     - If progress has not been evaluated, reassess progress

#### Events

1. **startEvent("Process Initiated")**
   - Purpose: Initiates the employee wellness program process

2. **endEvent("Process Complete")**
   - Purpose: Terminates the employee wellness program process
