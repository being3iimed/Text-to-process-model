Here's the BPMN pseudocode for the vendor evaluation process, following the canonical Pseudocode-to-JSON Mapping and emphasizing balanced, core-focused BPMN design:

```
startEvent("Vendor Evaluation Process Starts")

serviceTask("Define KPIs: delivery time, quality, responsiveness")

AND:
    serviceTask("Collect survey data")
    serviceTask("Conduct internal audits")
    serviceTask("Retrieve performance logs")
END_AND

scriptTask("Computation: calculate vendor scores based on KPIs")

serviceTask("Generate detailed vendor evaluation report")

if (vendor_score < threshold):
    sendTask("Send: improvement discussion request")
    userTask("Vendor responds to improvement plan")
    receiveTask("Receive: vendor improvement confirmation")
else if (vendor_score >= high_performance_threshold):
    sendTask("Send: incentive offer (extended contract/priority status)")
    receiveTask("Receive: vendor acceptance of incentive")
else:
    sendTask("Send: vendor maintained status notification")
endEvent("Vendor Evaluation Complete")
```

1. **Tasks**:

   - serviceTask("Retrieve performance logs")

   - sendTask("Send: improvement discussion request")
   - userTask("Vendor responds to improvement plan")

   - sendTask("Send: incentive offer (extended contract/priority status)")
   - receiveTask("Receive: vendor acceptance of incentive")
   - sendTask("Send: vendor maintained status notification")

2. **Gateways**:
   - XOR Gateway (if/else structure) for vendor score evaluation

3. **Events**:
   - startEvent("Vendor Evaluation Process Starts")
   - endEvent("Vendor Evaluation Complete")

**Design Justification**:

- **Core Elements**: Focused on tasks, gateways, and events as primary design elements (85%+ of design)
- **Boundary Events**: None used - no hard SLA requirements or critical error patterns identified
- **Subprocesses**: None used - no logical grouping, reusability, or complexity isolation needed
- **Gateway Selection**: XOR gateway used for simple decision (vendor score evaluation)
- **Task Sequencing**: Linear flow with parallel data collection (AND gateway) and simple branching (XOR gateway)
