### Summary of Elements

```
TASKS:
- userTask("Customer initiates return request") - manual initiation
- serviceTask("Validate return eligibility") - automated check
- sendTask("Send: return shipping label") - one-way communication
- receiveTask("Warehouse receives package") - waiting for response
- userTask("Verify item condition") - human judgment
- serviceTask("Process refund") - automated action
- sendTask("Send: refund confirmation email") - one-way communication

GATEWAYS:
- XOR at point after eligibility validation with conditions "eligible" and "not eligible"
- XOR at point after condition verification with conditions "acceptable" and "damaged"

EVENTS:
- startEvent("Process Begins") - manual initiation
- endEvent("Process Complete") - normal completion

BOUNDARY EVENTS:
- timerBoundary on "Validate return eligibility" - SLA: "within 30 days"
- errorBoundary on "Process refund" - Error: "refund processing failure"

SUBPROCESSES:
- Subprocess "Return Verification" - Purpose: "Verify item condition and determine refund eligibility"
- Justification: "Three-Question Necessity Test" - Can be described in one sentence, has 3+ related tasks, and improves readability
```

### BPMN Pseudocode

```pseudocode
startEvent("Process Begins")
userTask("Customer initiates return request")
serviceTask("Validate return eligibility"):
    timerBoundary("30 days"):
        sendTask("Send: return eligibility expiration notice")
if (eligible):
    sendTask("Send: return shipping label")
    receiveTask("Warehouse receives package")
    subProcess("Return Verification"):
        startEvent("Verification Start")
        userTask("Verify item condition")
        if (acceptable):
            serviceTask("Process refund"):
                errorBoundary():
                    userTask("Manual refund processing")
            endEvent("Refund Processed")
        else:
            sendTask("Send: return denial notice")
            endEvent("Return Denied")
        endSubProcess
    sendTask("Send: refund confirmation email")
else:
    sendTask("Send: return denial notice")
endEvent("Process Complete")
```
