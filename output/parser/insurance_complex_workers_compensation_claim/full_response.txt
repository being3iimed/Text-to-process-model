```
TASKS:
- userTask("Worker reports injury") - initial report
- serviceTask("Submit injury report") - employer action
- userTask("Contact injured worker") - adjuster action
- serviceTask("Collect injury details") - adjuster action
- serviceTask("Confirm medical facility") - adjuster action
- serviceTask("Determine injury coverage") - adjuster action
- serviceTask("Determine benefits") - adjuster action
- serviceTask("Verify worker's wage") - adjuster action
- serviceTask("Verify employment history") - adjuster action
- serviceTask("Authorize medical treatment") - adjuster action
- serviceTask("Review medical reports") - adjuster action
- serviceTask("Monitor work return") - adjuster action
- serviceTask("Order IME") - adjuster action
- serviceTask("Provide second opinion") - IME physician action
- serviceTask("Coordinate job placement") - adjuster action
- serviceTask("Receive status reports") - board action
- serviceTask("Calculate permanent disability award") - adjuster action
- serviceTask("Close claim file") - adjuster action

GATEWAYS:
- XOR at point X with conditions: injury work-related, injury not work-related
- XOR at point Y with conditions: benefits apply, benefits do not apply
- XOR at point Z with conditions: dispute arises, no dispute
- XOR at point W with conditions: worker can return to work, worker cannot return to work
- XOR at point V with conditions: permanent disability, no permanent disability

EVENTS:
- startEvent("Worker reports injury") - trigger: manual
- endEvent("Claim file closed") - normal completion

BOUNDARY EVENTS:
- timerBoundary on Task "Submit injury report" - SLA: 24 hours
- errorBoundary on Task "Submit injury report" - Error: report not submitted within 24 hours

SUBPROCESSES:
- Subprocess "Determine coverage and benefits" - Purpose: Determine if injury is work-related and what benefits apply
- Justification: Three-Question Necessity Test - Can be described in one sentence, has three related tasks, and removing it would make the main flow harder to read
- Subprocess "Monitor recovery" - Purpose: Monitor worker's recovery and authorize medical treatment
- Justification: Three-Question Necessity Test - Can be described in one sentence, has three related tasks, and removing it would make the main flow harder to read
- Subprocess "Handle dispute" - Purpose: Order IME and provide second opinion
- Justification: Three-Question Necessity Test - Can be described in one sentence, has two related tasks, and removing it would make the main flow harder to read
```

### BPMN Pseudocode

```pseudocode
startEvent("Worker reports injury")
userTask("Worker reports injury to employer")
serviceTask("Submit injury report"):
    timerBoundary("24 hours"):
        sendTask("Send: reminder to submit report")
    errorBoundary():
        userTask("Resubmit injury report")
serviceTask("Assign claims adjuster")
userTask("Contact injured worker")
serviceTask("Collect injury details")
serviceTask("Confirm medical facility")

subProcess("Determine coverage and benefits"):
    startEvent("Determine coverage and benefits start")
    serviceTask("Determine injury coverage")
    if (injury work-related):
        serviceTask("Determine benefits")
        serviceTask("Verify worker's wage")
        serviceTask("Verify employment history")
        endEvent("Coverage and benefits determined")
    else:
        endEvent("Injury not work-related")
endSubProcess

subProcess("Monitor recovery"):
    startEvent("Monitor recovery start")
    serviceTask("Authorize medical treatment")
    serviceTask("Review medical reports")
    serviceTask("Monitor work return")
    endEvent("Recovery monitored")
endSubProcess

if (dispute arises):
    subProcess("Handle dispute"):
        startEvent("Handle dispute start")
        serviceTask("Order IME")
        serviceTask("Provide second opinion")
        endEvent("Dispute handled")
    endSubProcess
else:
    pass

if (worker can return to work):
    serviceTask("Coordinate job placement")
else:
    pass

serviceTask("Receive status reports")

if (permanent disability):
    serviceTask("Calculate permanent disability award")
else:
    pass

serviceTask("Close claim file")
endEvent("Claim file closed")
```
