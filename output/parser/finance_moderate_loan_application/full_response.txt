### BPMN Pseudocode

```pseudocode
startEvent("Loan Application Submitted")
userTask("Submit Loan Application")
serviceTask("Perform Initial Validation")

if (validation_fails):
    sendTask("Send: Validation Failure Notification")
    endEvent("Loan Process Complete")
else:
    userTask("Loan Officer Review")
    userTask("Request Additional Documentation")
    serviceTask("Run Risk Assessment")

    if (approved):
        serviceTask("Generate Loan Terms")
        userTask("Accept Loan Terms")

        if (accepted):
            serviceTask("Fund Loan")
            endEvent("Loan Process Complete")
        else:
            sendTask("Send: Loan Rejection Notification")
            endEvent("Loan Process Complete")
    else:
        sendTask("Send: Loan Rejection Notification")
        endEvent("Loan Process Complete")
```
